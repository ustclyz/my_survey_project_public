  >>> 协议定义 (以官方定义为准):
    * 传输: JSON Lines, 一行一个 JSON 对象.
    * 外层协议版本: "participant-agent-protocol-v4"
    * 提交清单: 项目根 observer.project.json {"protocol":"jsonl-v4",
      "image":"python:3.12-slim","run":["python3","-u","agent.py"]}
    * 消息类型: initialize (无需回复) / decision_request / finish.
    * 回复: decision_response, 必须回填同样的整数 decision_sequence.
    * 动作字段 (来自官方 protocol.py 的 _RESPONSE_FIELDS):
        observe: pointing{alt_deg,az_deg} + assignments{纤维:"目标ID"} +
                 duration_seconds + program(DARK/BRIGHT/BACKUP)
        wait:    duration_seconds 或 until_utc (二选一, until 以 Z 结尾)
        report:  无字段
        finish:  无字段
      可选字段: reason, decision_source.
    * wallclock 字段: remaining_seconds (归一化 CPU 预算),
      remaining_real_cpu_seconds (本机真实 CPU 秒), wall_remaining_seconds
      (30 分钟硬上限剩余), speed_factor.
    * decision_request.payload 字段: schema_version, now_utc, survey_end_utc,
      observe_action_index, running_total, wallclock, latest_bulletin,
      latest_forecast, active_requests, new_messages, last_result.
    * initialize.payload 字段: schema_version, task_card, site{latitude_deg,
      longitude_deg,sun_altitude_limit_deg,minimum_altitude_deg},
      survey{start_utc,end_utc,slot_seconds,nights[]},
      instrument{n_fibers,grid_side,fiber_area_deg2,gap_deg,glass_side_deg,
      pitch_deg,fov_side_deg,exposure{...}},
      scoring{...}, footprint[], targets{columns[],rows[]}, limits{...}.

    A. llm.LLMPlanner.plan_night    -> 任务规划 (仅新夜调用, 带缓存)
    B. llm.LLMPlanner.decide_action -> 行动决策 (高层 observe/wait/report/finish)
    C. llm.LLMPlanner.diagnose_abnormal -> 计划自适应 (结果异常时, 加分项)
  预算保护: 绝不每轮调 LLM; 调用超时 30s, 重试<=2; 规划按夜缓存;
  按 wallclock.remaining_real_cpu_seconds 自适应锚点搜索规模 (pace 0/1/2).
  可审计: 每次调用的 system/user/返回写 stderr.
  静态回退: 无密钥/禁用/调用失败 -> 启发式 (标记 [static]), 无密钥也能跑通.
